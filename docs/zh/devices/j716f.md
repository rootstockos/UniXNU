# 联想小新 Pad Pro 2021（j716f）

SM8250 社区设备移植，由 Denis0x00 维护。

- [Denis0x00/UniXNU-j716f](https://github.com/Denis0x00/UniXNU-j716f)

## 当前状态

TB-J716F 已在实机运行菜单、音量键、电源键和内存 FAT / BlockIO。V14 记录确认 256 MiB 分配、缓存维护后的读回和释放，7/7 项检查通过。DarwinBoot v2 调用和无效负载拒绝已验证，XNU 入口和根卷集成待完成。

固件准备需要维护者的本地 UEFI 源码及厂商输入，仓库另有源码内核 CI 构建说明。

## 使用此移植

1. 阅读下方固定版本的源码说明和验证记录，准备该设备要求的固件和系统输入。
2. 克隆设备仓库，在检出目录内按其构建指南准备依赖：

```sh
git clone --branch main https://github.com/Denis0x00/UniXNU-j716f.git
cd UniXNU-j716f
git checkout f82228a9e166603d6a8b522bf0214db3379fad0d
git submodule update --init --recursive
```

3. 在该版本完成对应构建后，按[启动验证顺序](/zh/porting/bring-up)验证，并按[日志抓取](/zh/porting/log-capture)保存最后确认的阶段。
4. 将结果写入[移植记录](/zh/porting/records)。板级结构和组件选择见[移植设备](/zh/porting/steps)。
