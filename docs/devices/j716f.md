# Lenovo Xiaoxin Pad Pro 2021 (j716f)

A community port for SM8250, maintained by Denis0x00.

- [Denis0x00/UniXNU-j716f](https://github.com/Denis0x00/UniXNU-j716f)

## State

TB-J716F runs the menu, volume and power keys, and RAM FAT / BlockIO on hardware. The V14 record confirms a 256 MiB allocation, cache-maintenance readback and release, with 7/7 checks passing. DarwinBoot v2 invocation and invalid-payload rejection are tested. XNU entry and root integration remain pending.

Firmware preparation requires the maintainer's local UEFI tree and vendor inputs. The repository documents a separate source-kernel CI build.

## Use this port

1. Read the pinned source and validation records below. Prepare the required firmware and system inputs.
2. Clone the device repository and follow its build guide from the checkout:

```sh
git clone --branch main https://github.com/Denis0x00/UniXNU-j716f.git
cd UniXNU-j716f
git checkout f82228a9e166603d6a8b522bf0214db3379fad0d
git submodule update --init --recursive
```

3. Complete the build for that revision, follow the [bring-up order](/porting/bring-up), and use [log capture](/porting/log-capture) to record the last confirmed stage.
4. Save results in the [porting record](/porting/records). See [Port a device](/porting/steps) for board structure and component selection.
